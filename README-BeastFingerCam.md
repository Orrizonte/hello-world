# Beast FingerCam (Android camera diagnostic only)
This build is an isolated Android app to verify that Viture Beast RGB camera works on Honor Android.
It does NOT draw transparent fingers yet. No keyboard input is injected.
Camera USB IDs 0C45:6368. Requires Viture Android SDK (libglasses.so) installed during build.
DO NOT commit proprietary SDK libraries or headers.
The code is in the branch build/beast-fingercam-android-20261031 and leaves master unchanged.
